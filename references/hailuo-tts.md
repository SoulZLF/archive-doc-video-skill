# 海螺 / MiniMax TTS 语气控制

海螺（hailuoai.com/audio）默认挂 `speech-2.8-hd`，**支持把标记直接写进正文**，生成时自动生效。

## 三种内联标记

### 1. 情绪标签（主力）

```
{sad}假装自己别无选择。{/sad}
```

只能用这 8 种，**逐句包，不要包整段**：

```
happy  sad  angry  fearful  disgusted  surprised  neutral  fluent
```

- 单次请求**最多 15 段**。
- 官方说明：情绪标签**不计费**（语气词和停顿算字数）。
- `fluent` = 生动流畅，适合罗列或推进句；`neutral` 是默认，打了等于没打。

### 2. 语气词（仅 speech-2.8-hd / 2.8-turbo）

半角括号，直接嵌在句中：

```
(breath) (inhale) (exhale) (sighs) (emm) (laughs) (chuckle) (clear-throat)
(coughs) (gasps) (pant) (sniffs) (snorts) (groans) (humming) (hissing)
(sneezes) (burps) (lip-smacking)
```

- `(breath)` 放在情绪重音句前，是最便宜的「像真人」手段。
- `(emm)` 做迟疑、思考的停顿。
- `(sighs)` 放在一个下沉的判断句前，效果极强，但**全片最多一次**。
- 这些标签是**文本内容的一部分**，不要塞进 `voice_setting.emotion` 参数。

### 3. 停顿标记（慎用）

官方允许在文本里插定时停顿（0.01–99.99 秒，必须夹在两段可发音文字之间，不能连续用、不能放首尾、不能连续用）。
但**具体符号在公开文档和第三方资料里长期被转义吞掉，无法 100% 确认**。
写错会被原样念出来（「小于号井号零点五井号」）。

→ **除非用户明确说自己试过、确认可用，否则不要写停顿标记。**
标点本身就能控呼吸，官方也建议这么做：逗号、句号、问号直接决定模型在哪换气。

## 情绪配比：这是最容易做错的地方

8 种情绪里**没有「克制」这一档**。冷静思辨类内容如果满篇贴情绪标签，一定会演过头：

- `{sad}` 用多了 → 哭腔
- `{fluent}` 用多了 → 广告腔
- `{angry}` 用多了 → 吵架节目

**正确配比（3 分钟片）**：
- 绝大多数句子**不打标签**（留 neutral）；
- 只在最关键的一两句用 `{sad}` 或 `{fluent}`；
- 语气 70% 靠 `(breath)` 和标点，30% 靠情绪标签。

例：一句「假装自己别无选择。」——与其贴 `{sad}`，不如前面加一个 `(breath)`，
因为观众听到的是「他先吸了口气，才说出这句话」，而不是「他在演难过」。

## 生成设置

| 项 | 值 |
|---|---|
| 音色 | 按内容选。思辨/商业类用「沉稳高管」或同类中年男声 |
| 语速 | **0.9–0.95**。不要 1.0，快了气口全乱 |
| 模型 | `speech-2.8-hd`（语气词只在这个模型生效） |
| 语言 | 手动选「中文」，不要依赖自动识别 |
| 分段 | 按幕分段导出（5 段），不要合并成一条 |

## 交付给用户的格式

用户要的是「粘进去就能生成」，不是「拿来读的文档」。

- **一整段纯文本**，可复制；
- 不要表格、时间码、镜头号、语气批注；
- 段落之间空一行即可（= 幕与幕之间的换气）。

如果需要解释语气处理，写在**正文之外的对话里**，不要混进可复制的正文。

## 生成后必须做的两件事

1. **先拿第一段试一次**，确认标签生效（没被念出来、没有漏读）。
2. 用 `ffprobe` 量真实时长，和预期比对；差 >5% 说明语速不对，回去调 0.9 重生成，
   不要靠后期拉伸——拉伸会让气口全变形。
