# 封面帧

封面不是出片后裁一张，是**开拍前就定好位置**。用户会在 25 格里圈一格，
那一格必须同时满足三件事：物在画面里、标题在画面里、裁成 3:4 之后两者都还在。

## 三个比例与裁切窗（源片 1080×1920）

| 用途 | 尺寸 | 纵窗 | 说明 |
|---|---|---|---|
| 小红书（主用） | 1080×1440 | y 240–1680 | 双列瀑布流按 3:4 显示，不会被二次裁 |
| 视频号 / 抖音 | 1080×1920 | 全帧 | 原封不动 |
| 公众号 / 信息流 | 1080×1080 | y 420–1500 | 方图 |

## 安全区是硬的

档案体的版面：舞台 280–980，图注 1000，尺规 1046，**标题块 1216 起、到 1500 左右**。

3:4 只有 1440 高，要同时包住「舞台顶 280」和「标题底 1500」→
**纵窗起点只能落在 60–280**。默认取 240（舞台上方留 40px 呼吸）。

```
y = 60    → 上边距 220，下边到 1500，标题贴着裁切边（危险）
y = 240   → 默认。舞台顶留 40，下边到 1680，副标下方留 180
y = 300   → 舞台顶被切 20px。只有当这一镜的物不顶到 280 时才安全
y = 440   → 会把页脚 SOURCE 切在半行上，像排版事故
```

`make_cover.py` 会自己算并警告，不用记。

## 分镜阶段的约束

1. **每一镜都要能当封面**：物不要贴到 280（至少留 30px），标题块不要超过 1520。
2. **不要用页脚承载信息**——1850 之后的东西一定进不了 3:4。
3. 每幕至少留一镜「构图上顶天立地、有结论」的，作为该幕的封面候选。

## 视频要跟着封面走

用户圈定封面帧后，成片不能只是"能截出这一帧"，要让它**在片子里留下痕迹**：

- 若封面帧是**某一幕的落点**（印章、盖章、结论），就把该镜尾部的停留延长 0.6–1.0 s，
  让平台自动抽帧时也大概率落到它旁边；
- 若封面帧是**片中某一瞬**，在该瞬之后补一个 0.4 s 的静止段（`upd` 的 u 不变，只有整体缓推），
  避免抽到动作中间态；
- 开场首帧（video thumbnails 默认取第 1 帧）不要放信息量低的空镜。

## 命令

```bash
# 从成片抽 03:06.6 那一帧，出三档封面
python scripts/make_cover.py 成片.mp4 186.6 --tag 第14集

# 指定纵窗（这一镜的物不顶到 280 才敢往下挪）
python scripts/make_cover.py frames3 186.6 --y 300 --ratios 34,916
```

输出：

```
封面_1080x1440_3比4.jpg
封面_1080x1920_9比16.jpg
封面_1080x1080_1比1.jpg
cover.json          # 记录时间点与纵窗，返工可复现
```

## 小红书封面的可读性下限

缩到 340px 宽（瀑布流实际显示宽度）还要能看清：

- 大标题 ≥ 96px（在 1080 宽里）
- 印章/主体 ≥ 画面宽度的 35%
- 不要指望 15px 的 mono 小字，那是质感不是信息
