# 坑清单（按症状索引）

## 画面全黑，只有标题在

**症状**：截图出来舞台区域全空，console 无报错。
**原因**：镜头组件内部新建了容器但没有 append 到传入的 root，整棵树脱离 DOM。
**修法**：`function newShot(root){ const s=mk('div','stage'); if(root) root.appendChild(s); ... }`，
每个 kit 签名必须是 `function(root)`。

这个 bug 极其隐蔽，因为不报错。**超过 2 张截图都有问题，先查挂载，再查样式。**

## 翻转镜头翻出来的是背面

**原因**：两面的 `rotateY` 写反了。
**修法**：初始可见的那一面不转，要露出的那一面放 `rotateY(180deg)`，父级转 0→180。
配 `backface-visibility:hidden` + 父级 `transform-style:preserve-3d`。

## 某一镜永远不出现，且不报错

**症状**：最后一镜（或任意一镜）画面静止、动画全无，但 console 干净。
**原因**：`ACTSHOTS[i]` 与 `WEIGHTS[i]` 长度不一致。循环按 ACTSHOTS 走，
多出来的那一镜取到 `undefined` 权重 → 时长算成 `NaN` → `s.a` 是 `NaN` →
`t >= NaN` 恒为 false → 永远匹配不到，`render()` 兜底到最后一项，`upd(NaN)` 失效。
**修法**：加一行断言，长度不一致立刻 throw：

```js
ACTSHOTS.forEach((n,i)=>{ if(WEIGHTS[i].length!==n)
  throw new Error('WEIGHTS['+i+'] 长度应为 '+n); });
```

**这个坑极难发现**——画面不是黑，是「停在第一帧」，看起来像动效没做完。

## 抽帧 QC 时误判「动画没做完」

**症状**：检查成片时抽某个时间点的帧，画面比预期「早」，像动效还没开始。
**原因**：`-ss` 放在 `-i` **前面**是快速 seek，会落到最近的关键帧，
最多能差 2 秒（我们设了 `keyint=60`）。
**修法**：QC 抽帧一律把 `-ss` 放到 `-i` 后面：

```bash
ffmpeg -i film.mp4 -ss 36 -frames:v 1 q.png      # 准确
ffmpeg -ss 36 -i film.mp4 -frames:v 1 q.png      # 会偏，别用
```

**更好的办法**：直接拿渲染出来的 `frames/f_XXXXX.jpg` 拼分镜表，
既准又快（帧号 = 秒 × fps），不用再解码一遍视频。

## 改了文字只想重渲一部分

时间码没变、只改了一句文案（比如把年份 1934 改成 1943）时：

```bash
# 只重渲受影响的那一段帧（第 2 幕 = 帧 1054–2026）
python scripts/render_frames.py index.html frames 30 174.75 1054 2026
# 然后整片重编码（4 分钟，不能省）
bash scripts/encode.sh frames assets/mix.m4a out.mp4
```

**关键**：只要改的是**画面内容**而不是**时间**，帧号就不会错位，可以局部重渲。
一旦动了 `VODUR` / `WEIGHTS`，全部帧作废，必须整片重跑。

## 暗片在手机上看不清

**原因**：结构线用的是 `#3A403C` 这类接近黑的灰，视频压缩再吃掉 1–2 档。
**修法**：结构线整体提亮一档（`#3A403C → #5A615C`，`#4A504C → #6E7671`）；
暗角从 `rgba(0,0,0,.66)` 降到 `.48`，起始位置从 36% 推到 46%。

## 长镜后半段像卡住了

**原因**：动效在 3 秒内全做完，剩下 10 秒静止。
**修法**：13 秒以上的镜头，在 6 秒左右补第二动作（抹除 / 滑落 / 翻转 / 数据叠层）。

## 标题和画面数字撞车

**症状**：标题写「64% 的年轻人」，画面里也是一个巨大的 64%。
**修法**：标题只出**论点**，不出数字；数字归镜头。同理，最后一镜的结论不要提前写进标题。

## `Invalid or unexpected token`

**原因**：多行字符串用了单引号。
**修法**：一律模板字符串。写完用 `node --check` 过一遍提取出的 script。

## `getTotalLength()` 返回 0

**原因**：元素还没挂到 DOM。
**修法**：懒计算——第一次 `upd()` 里再去取，取不到就用兜底常量。

## `-filter_complex_script` 不存在

**原因**：ffmpeg 9 移除了这个选项。
**修法**：`-filter_complex "$(tr -d '\n' < x.filters)"`。注意把换行和行首空格都去掉，
否则滤镜链会被拆断。

## 片尾 4 秒静音

见 `audio-mix.md` 的坑 ①。**交付前必须单独量片尾 3 秒。**

## 配乐盖过人声

见 `audio-mix.md` 的第一原则。根因几乎总是「没量 RMS 就写 volume」。

## 渲染中途卡死 / 越来越慢

**原因**：单页循环 seek 会累积内存。
**修法**：每 1000 帧重启一次 page；或先 bench 30 帧估算总时长，超过 40 分钟就分批跑。

## 磁盘撑爆

1080×1920 的 JPEG q96 约 200 KB/帧，5730 帧 ≈ 1.2–2 GB。
先 `df -h` 看剩余，中间帧**用完即删**——改一个时间码全部帧都失效，留着没意义。
