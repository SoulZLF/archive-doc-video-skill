# 视觉系统

系列化的关键：这套东西一帧不改，只换「器械」。观众看第二支时一眼认出是同一条片子。

## 三色

```
Ink    #08090A   真黑。不要用灰绿或深蓝黑
Paper  #EDE7DA   暖纸白。只出现在「文件 / 便签 / 牌面」等实体材质上
Red    #DE3B27   只用于「被系统标记的东西」：一个 LED、一条进度尾段、一道划掉的线、一枚印章
```

**红色一旦也用来做装饰，强调就失效了。** 任何新元素想用红色之前，先问：它是不是被「标记」的那个东西。

结构线色阶（在暗底上要和黑拉开距离，视频压缩会吃掉 1–2 档）：

```
#1D201F  最弱  分隔
#2A2F2C  弱   衬线
#3A403C  → 提亮后 #5A615C   中  图形轮廓
#4A504C  → 提亮后 #6E7671   强  主要线条
#8A918C  次级文字
#B4AE9E  强调文字
```

## 三字体

```
标题      Noto Serif SC      重字（700），字号 100–136
数字/标签  Cascadia Mono      ——「仪器感」的根。所有时间码、编号、数据点都用它
辅助      Noto Sans SC      27–30px
```

**中文标题用宋体、数字用等宽，这一组搭配就是「档案 + 仪器」的全部味道。**
混用字体会立刻变成 PPT。

## 栅格（1080×1920）

```
0 – 180       文件头：FILE NO.xx — RESTRICTED  /  走秒时间码  /  细分隔线
150           副信息：系列名 · 日期 · DRAFT
280 – 980     视觉舞台（912 × 700）
1000          图注行：FIG.xx / 名称  …  右侧数据点
1046          尺规横带：细刻度 + 红色游标跟真实时间走
1216 –        标题块：kick（ACT 编号 + 中文标签 + 右侧出处）/ 主标题 / 副标
1850          页脚：SOURCE / 署名
```

**尺规横带是贯穿全片的装置**，有没有它，决定观众觉得这是「一支片子」还是「25 张图」。

## 底色层（三件套，别省）

```css
颗粒  canvas 噪声，12fps，mix-blend-mode: overlay，7%
暗角  radial-gradient，transparent 46% → rgba(0,0,0,.48)   /* 比 .66 更亮，暗片要留透气 */
扫描线 repeating-linear-gradient，0 1px / 3px，2.8%
```

## 动效参数表

| 动作 | 参数 |
|---|---|
| 文字入场 | 每行 stagger 140ms，`translateY 105%→0`，`easeOutCubic` |
| 遮罩入场 | 用父级 `overflow:hidden` + 子级 `translateY`，不要用 opacity |
| 数字累加 | `1-(1-p)^5`（easeOutQuint），2.2–2.6s |
| 曲线绘制 | `stroke-dasharray/offset`，头部挂 6px 圆点跟着 `getPointAtLength` 走 |
| 方格点亮 | 对角序 `clamp01(p*1.5 - (r+c*0.55)*0.011)` |
| 雷达扫描 | `rotate(u*42deg)` + `conic-gradient` 296°→360° 渐显 + 径向 mask |
| 镜头推进 | `easeInOut` 到 2.6×，之后**继续 +0.14 缓推**，全程不静止 |
| 印章落下 | `scale 2.4→1`，0.46s，落定后 4 帧抖动 |
| 翻牌 | 父 `perspective:1200px`，子 `transform-style:preserve-3d`，两面 `backface-visibility:hidden`，**牌面放 180°** |
| 换镜 | 0.10s 淡入（3 帧）+ 0.07 白色闪帧 |

## 三种「入场方式」，只用这三种

1. **打字机**——文字
2. **数值累加**——数字、进度
3. **机械通电**——图形：先 1px 骨架线，再填充，再稳定

没有位移飞入，没有弹跳，没有 scale-bounce。克制是这个风格的命。

## 线稿型镜头的亮度下限

只有线条、没有色块填充的镜头（岔路、分屏、天平、同心圆），在暗底上极易糊成一团。
**这类镜头的结构线至少要 `#5A615C`，主线条 `#6E7671`，关键构件 `#8A918C`。**

第二次做片时，两镜（岔路 / 分屏）投到手机上看几乎是黑的——预估时觉得「有质感」，
实际是「看不见」。判断标准：缩到 340px 宽还能分辨出图形结构，才算过。

## 长镜的补动

超过 13 秒的镜头，在 6 秒左右补一个第二动作（抹除 / 滑落 / 翻转），
否则后半段观众会以为视频卡了。
