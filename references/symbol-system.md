# 象征系统：把概念换成物，再用母题把它们串起来

「图示」和「当代表达」之间差一层东西：**有没有物**。
观众记不住同心圆，但记得住一只空碗。这一页讲怎么找物、怎么复用物、怎么让一条母题贯穿全片。

---

## 一、找物：每个抽象概念都有一个可以叫出名字的替身

不要问「这个镜头怎么画」，问「这个概念在现实里长什么样」。

| 抽象 | 图示（廉价） | 物（有分量） |
|---|---|---|
| 差序格局 | 六个同心圆 | **一滴墨落在纸上，晕开，最外圈已经干成断续** |
| 界限被切硬 | 圆被三条线切 | **一张画着圈的纸被裁成四块，四块错位，缝里露黑** |
| 他者之脸 | 侧脸线稿 | **一张证件照**：相纸边框、深底、头和肩的剪影、一道轮廓光 |
| 自我所有权 | 三条进度条 | **一张登记表**，三行栏目各盖一个红勾 |
| 边界不是墙 | 矩形轮廓线 | **门口一块有厚度、有编织纹的地垫** |
| 被榨干 | 容量条 8% | **桌上一只空碗、一双筷子、一道长影** |
| 舆论 vs 法条 | 刻度尺+指针 | **剪报的标题被红笔划掉，压着法条页，"协助"被红笔圈住** |
| 时间与断裂 | 时间轴+节点 | **档案卡上四枚日期戳**，最后一枚是红的 |
| 出钱/出力/同住 | 三个方格 | **三张并排的单据**，各带编号与勾选框 |

判断标准一句话：**能不能指着说"这是某某"**。只能指着说"这是一个圆"的，回去重做。

---

## 二、找完之后，把它们编成一个母题

物是点，母题是线。线扎住了，全片才有纵深；散着放，25 个好东西也只是 25 张好图。

母题要有三个性质：

1. **可复现**：同一形态至少出现三次，且分布在不同幕。
2. **可变形**：每次出现的材质/尺度不同（线→缝→划痕→印章→框）。
3. **可转义**：前半段是"限制"，后半段必须变成"保护"或"承认"。

### 本集的母题：一条红线

| 幕 | 出现 | 形式 | 这一段的含义 |
|---|---|---|---|
| Ⅰ | 01 门 | 横向红线压在门槛上 | 界线：人止步于此 |
| Ⅱ | 10 裁纸 | 三条黑缝（红线的负形） | 界线被切成硬边 |
| Ⅱ | 11 尺与墨 | 沿尺边画的一道黑线 | 界线是**画出来的**，不是天然 |
| Ⅴ | 20 剪报 | 红笔划过标题 | 界线变成**判断**：谁被划掉 |
| Ⅵ | 25 印章 | 红色方框落定 | 界线变成**承担** |

同一条线，从"拦人"变成"担责"。这个转义不需要旁白解释，观众看形状就懂。

其他可用的母题形态：**门 / 门槛 / 缝 / 手写的线 / 印章 / 折痕 / 装订孔 / 光斑**。
选一个和题材天然同源的——讲家庭伦理就用门和门槛，讲户籍就用章和本，讲劳动就用工时表。

---

## 三、不要做的事

- **不要用一个物解释两个概念**。物的歧义会稀释它。
- **不要 25 镜都用同一种材质**。纸、黑底、暗块要交替；连续三格同调，观众就滑走了。
- **不要在物上加注释框**。"这是象征边界的门槛"——一旦解释，象征就死了。
  要解释，交给口播；画面只负责让它存在。
- **不要为了象征牺牲可读性**。缩到 340px 宽认不出的物，等于没有。

---

## 四、动效的象征动作

象征物的动效不能只是"淡入"，它要做一件与语义同构的事：

| 物 | 动作 | 语义 |
|---|---|---|
| 门 | 门缝的光从细到宽 | 里面有人生活 |
| 墨滴 | 一圈圈推开，最外圈干断 | 关系愈远愈薄 |
| 裁开的纸 | 四块各自错位 4–16 px | 被切开，不是被画线 |
| 证件照 | 光带掠过，脸才浮出 | 看见才产生责任 |
| 印章 | scale 2.4→1，落定后 4 帧抖动 | 决定不可撤回 |
| 纸带 | 一直抽向画外，不停 | 要求是无限的 |

一个判断：如果这个动作换到别的物上也成立（比如"淡入"），那它就不是象征动作。
