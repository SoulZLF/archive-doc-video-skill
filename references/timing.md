# 时长：估算、实测、切点

这是整套流程里最容易翻车的一环。第一版估长了 7%，第二版又按旧系数算，
导致切点全要重排。下面是从两次实测校准出来的数。

## 一、估算（还没拿到配音时）

**快估**：`秒数 ≈ 总字符数（含标点） / 4.9`

实测校准：837 字符（含标点）→ 169.95 秒 = **4.92 字符/秒**。
适用于「沉稳高管」这类中年男声、语速设在 0.9–0.95 的情况。

**细算（逐句，用于排版面）**：

```
每句 = 去标点字数 / 5.2 + Σ标点停顿

标点停顿：。0.35    ，0.18    ；：0.25    ——0.15
```

> 第一版用的是「字数/4.8 + 较大停顿（。0.45）」，结果 803 字估成 182 秒，
> 实际 170 秒——**估长 7%**。停顿给太足了，TTS 读得比人快。

**估算只用来排版面和定分镜，绝不用来定切点。**

## 二、实测（配音到手后）

```bash
ffprobe -v error -show_entries format=duration -of default=nw=1 vo.mp3
ffmpeg -i vo.mp3 -af "silencedetect=noise=-32dB:d=0.28" -f null -
```

`duration` 就是真实总长。先和估算比：

- 差 **< 5%** → 直接用。
- 差 **5–10%** → 用实测时长，切点全部反算。
- 差 **> 15%** → 语速不对，回海螺把 speed 调到 0.9 重新生成。
  **不要用 ffmpeg 拉伸**——拉伸会把气口全拉变形，比重新生成还糟。

## 三、幕界怎么定

`silencedetect` 会吐出成对的 `silence_start` / `silence_end`。

判读要点：

1. 先筛出 `duration > 0.9` 的（实测 170 秒的片子有 109 个停顿，其中只有 19 个超过 0.85 秒）。
2. **不要挑最长的，要挑「离语义边界最近的」**。
   一个 1.2 秒的停顿如果在句子中间，切在那里就是灾难。
3. **语义边界不一定有长停顿**。TTS 会把段落连着读。
   这时候就切在句号后 —— 宁可切在 0.2 秒的小缝里，也不要在句子中间找一个 1 秒的缝。

实测例（169.95 秒，五幕）：

```
34.80 → 35.90   1.10s   停顿，正好在「萨特说」之前   ← 用 34.05
66.28 → 66.53   0.25s   句号缝                        ← 用 66.40
98.61 → 98.81   0.20s   句号缝                        ← 用 98.70
134.5 附近无停顿 → 切在「所以回到最开始那个问题。」之后  ← 用 137.60
159.41 → 159.56 0.15s   句号缝                        ← 用 159.50
```

## 四、整段 vs 分段：这是个关键选择

| | 整段（1 个 mp3） | 分段（5 个 mp3） |
|---|---|---|
| 语气连贯性 | **好**，一口气读完 | 每段重新起调，接缝处音色会飘 |
| 幕界定位 | 靠 silencedetect 反推 | 天然存在，直接量 |
| 时间线 `GAP` | **必须设 0** | 可以留 0.3–0.5 秒 |
| 推荐 | ✅ 优先 | 只在用户明确要求时 |

**用户的真实行为是：把整段文案一次性粘进海螺，得到一个文件。**
即使你在口播稿里分了段，也要按「可能只给一个文件」来设计流程。

**`GAP` 不为 0 会怎样**：音频连续、画面每幕却插 0.5 秒空隙，
到第五幕画面已经落后 2.5 秒，完全对不上，而且不会报错——只会觉得「怎么越看越怪」。

## 五、反算 WEIGHTS

```
幕内第 j 镜权重 = 该镜覆盖的台词时长 / 幕总时长
台词时长 = 该镜最后一句的结束时间 − 该镜第一句的开始时间
```

算完写死进 `WEIGHTS`，**不要手调**。手调就是在拿感觉对抗实测。

自检两条，缺一不可：

```js
Σ(VODUR) === 音频总时长
WEIGHTS[i].reduce((a,b)=>a+b) === 1   // 每一幕
WEIGHTS[i].length === ACTSHOTS[i]     // 长度必须一致
```

第三条最容易忘，代价是那个镜头的 `a` 变成 `NaN`，永远不播放且不报错。

## 六、长镜预警

反算完，**先扫一遍每镜时长**：

- **> 13 秒** → 必须设计第二拍。第二段动作在 6–10 秒之间启动，
  否则后半段是静止画面，观众以为视频卡了。
- **< 3 秒** → 检查这个动作能不能在 3 秒内演完；不能就把边界挪到相邻的逗号处，
  牺牲一次对齐换一次可看性。

第二次做片时有两镜超标（15.0s 的「岔路」、12.6s 的「天平」），
都是靠这一步才发现的——不是靠看片时觉得「有点闷」。
